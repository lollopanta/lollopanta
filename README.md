## 👋 About Me

I'm **Lorenzo Pantalone**, a student developer based in Italy. I enjoy turning ideas into working software, from backend systems and web apps to developer tools.

- 🧩 **What I build:** full-stack applications, APIs, automation and developer tooling.
- 🤖 **What I'm exploring:** AI-assisted development, agent workflows and better developer experiences.
- 🧠 **What I'm learning:** product discovery, software architecture and designing around real users.
- 🤝 **What I enjoy:** collaborating with motivated people, sharing knowledge and building as a team.
- 🎯 **What matters to me:** useful products, clear engineering decisions and continuous improvement.

## ⭐ Featured Projects

### 🔐 [MilestonePay](https://github.com/lollopanta/MilestonePay)
A prototype for milestone-based freelance payments, with on-chain escrow, private deliverables and verifiable settlement history.

`TypeScript` · `React` · `Fastify` · `Avalanche` · `Swarm`

### 🖼️ [@lollopanta/mdtoimage](https://github.com/lollopanta/mdtoimage)
A Node.js library and CLI that turns Markdown into PNG or SVG images using Satori and Sharp — no headless browser required.

`TypeScript` · `Node.js` · `Satori` · `Sharp`

### 📋 [Projex](https://github.com/lollopanta/Projex)
A collaborative task-management app with projects, permissions, reminders and a full-stack web architecture.

`React` · `Node.js` · `Express` · `MongoDB`
